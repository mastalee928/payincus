1. 候选提交的源码CI全部终态，无未处理失败，逐job实际checkout和候选tree身份一致。
2. 同提交双架构预览构建/首装及恢复演练通过；预览Release预期跳过。
3. main快进到同提交，正式注释tag固定指向候选；正式双构建、双首装及Release成功后实际下载六资产。
