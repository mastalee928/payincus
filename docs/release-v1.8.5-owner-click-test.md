# v1.8.5 网页升级与检查

由管理员自行操作。核对[正式Release](https://github.com/mastalee928/payincus/releases/tag/v1.8.5)和[验证记录](release-v1.8.5-validation.md)中的最终来源及资产；发行完成不代表生产已升级。

## 升级与下载

1. 管理后台「版本更新」(`/admin/system-update`)检查更新，记录当前版本、时间与任务编号，目标应为稳定v1.8.5。
2. 点击更新一次，等待下载、备份、迁移、校验与唯一后台重启完成。回到版本页确认1.8.5、源码及部署时间，失败记录具体阶段和回滚结果。
3. 本包包含永久下载修复；安装后遇暂时下载故障会有限重试，必要时切换官方资产API，完整性错误仍拒绝安装。旧版本首次升级使用旧下载器；不能因为新包包含修复就保证旧端首次下载免故障。若仍在下载阶段失败，保留任务日志，不反复点击或绕过hash/签名保护。
4. 正常成功后不必为了验证重试而再次安装、人工制造故障或下载同包。本版累计241迁移、无新增迁移，Agent继续为v1.0.5；核机器池实际心跳与版本。

## 首页

1. 电脑先实际选中一个有库存地区，看底部地区卡相对地图水平居中；再切洲、点城市、缩放/复位，核名称和购买目标一致。
2. 调整窗口到1604×1034、1280×560、1440×500和1920×600附近，确认地区卡不被图例或缩放按钮遮挡；平板横竖切换同样检查。
3. 手机打开导航，再点语言选择，应只保留语言菜单。测试三语、深浅主题、触摸和Escape，购买/登录入口正常。
4. 手机「全部」无城市文字，选洲后显示附近名称；核春川、新加坡、新加坡西部、瓦尔帕莱索与欧洲地区。主标题/品牌/导航禁选保持，表单输入正常。

## 原有业务与运行状态

使用专用测试账户与授权测试实例检查登录、余额/订单、充值到账和续费金额，重复回执不重复扣款。检查管理员改邮箱铅笔、改到期时间入口、已配置网关只读重新检查及原在线宿主。安全维护显示真实原因，原客户SSH密码、IP/IPv6与转发保持。其余已发行功能的详细检查沿用[v1.8.4检查表](release-v1.8.4-owner-click-test.md)。

「阿里云OSS」查看完整备份任务的实际结果，正常升级无需还原。管理员日志按本次时间和任务查下载/更新、回滚、登录及业务异常。不要为验证清除隔离、修改生产账目、重启客户或改变DNS/IP；真实新B灾备等仍需独立验收。
