# v1.8.8 更新后检查

v1.8.8修复旧网关组件导致的升级回滚，并保留v1.8.7的全部业务修复；配套Agent仍为v1.0.7。本轮未代更新生产主控。

1. 管理端按正常在线更新流程升级至v1.8.8，任务完成后确认版本为v1.8.8、唯一后端健康。当前v1.8.6回滚状态可直接升级；已成功执行的续费价迁移会保留且不会重复添加，无需手动改数据库或重建网关身份。
2. 主控和网关持续校时助手会随包安装。`scheduled`只表示已安排，实际以新鲜状态中的`synchronizing`／`synchronized`为准。正常约14秒偏差由签名心跳及同次固定Incus响应时间处理；真实防护失败仍保留不可售原因。
3. 观察机器池数轮心跳及五分钟巡查，确认不再因旧时钟判断反复不可售，并查看具体失败原因。不能仅凭发布成功认定全部生产宿主已恢复。
4. 续费改价仅在管理员当前实例详情可用；用户和宿主所有者无入口。删除清理回池后新销售按原机器池定价，不继承旧实例override。
5. 池宿主Agent到v1.0.7后后台跟进宿主BBR，无法安全开启仍按原算法销售，不改客户实例算法。确认到期实例实际Stopped、保留期结束后Incus容器／磁盘／快照／转发清理确认再回池。

完整版本、公开资产及实际旧worker升级证据见[发行记录](release-v1.8.8-validation.md)。正式双首装、六种旧版升级包含正常旧版、已迁移原子回滚状态、故障注入后自动回滚再升级；测试机成功不替代目标主控升级后的实际观察。
