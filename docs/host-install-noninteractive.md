# 节点脚本的非交互执行

Ubuntu / Debian 节点脚本 `server/templates/install.sh` 支持从面板下载注入当前参数的脚本后，在专用目标机器上非交互运行。必须提供网络模式 `--mode nat` 或 `--mode nat_ipv6`、当前安装 token，以及明确确认参数 `--yes`（简写 `-y`）；面板已经注入模式或 token 时可复用注入值。

例如，已注入 token 的本地脚本可使用 `sudo bash node-install.sh --mode nat --yes`。不要把真实 token 写进公开说明、日志或截图。需要自定义通信端口时再传 `--port 10001`；非交互未传端口自动使用 8443，Agent 上报间隔保持 60 秒。

缺少参数或确认、非法模式/端口会在系统探测与安装前退出，不会等待终端。`--yes` 只确认安装；卸载、Agent 管理菜单仍需交互终端。正常交互安装保留原来的模式、token、端口和确认提示。

此入口属于现有手工节点安装脚本；管理员创建客户实例仍使用机器池一机一卖，网关页面的自动接入和恢复流程保持各自验证与授权边界。
