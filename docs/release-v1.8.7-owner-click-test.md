# v1.8.7 更新后检查

面板v1.8.7及Agentv1.0.7已公开并核验双架构首装／恢复与资产；本轮没有代部署生产。面板应配套Agent v1.0.7，只有面板更新不能证明旧宿主BBR已应用。

1. 管理员实例详情「信息→基本信息→续费价格」铅笔设置当前实例下期最终价；保存后再次读取一致。用户／宿主所有者页面没有改价入口。当前余额、已付款账单及到期保持。
2. 手动／自动续费采用已确认最终价；没有额外AFF／VIP折扣。旧实例完整删除后回池新销售按原机器池定价，新实例不继承旧价。
3. 管理员查看五分钟巡查记录，可按日期、用户、停机、删除、失败搜索，具体目标／原因／下次自动处理保持。已到期未续费实例Incus实际Stopped，不能只看主控封停。
4. 系统到期封停满72小时未续费后，原Incus容器／磁盘／快照／转发已不存在才释放库存；暂时失联、任务忙或丢回执恢复后自动续接。
5. 已接入和新接入池宿主Agent到配套版本后后台核host BBR；能修的自动修，确实不能开启保留原算法仍售卖。客户实例算法和运行状态保持，BBR不触发客户开关机。
6. 手动续费解除到期封停为Stopped，由客户启动；自动补续核原实例后恢复，失败不重复扣款。手动／风控封停不自动解除。

上线检查和本地／CI／Release证据分别记入台账，不能以后台状态图标代替实际Incus及账务核验。
