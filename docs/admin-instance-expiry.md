# 管理员修改实例到期时间

适用下一版源码，入口：管理员后台 → 用户实例详情 → 信息 → 基本信息 → 到期时间旁「修改」。已有期限的实例可编辑，日期时间精确到秒，按当前设备时区输入；弹窗显示时区及该日期对应的GMT偏移，后台以UTC保存。

仅当前有效管理员可用。普通客户、宿主所有者、Public API/PAT/OAuth token均不能读取改期凭据或修改到期时间；用户端安装包不包含改期弹窗和API调用代码。后台验签后查数据库当前角色、账户状态及会话撤销，保存事务内再次锁定复核，不能通过更改页面、请求中的role或旧管理员token取得权限。客户正常付费续费流程保持原规则。

## 行为

- 可提前或延后到期时间；不扣款、不退款、不伪造续费账单，原自动续费开关保持。
- 保存后清除旧提醒/续费尝试计数，使现有巡检按新日期判断。自动续费开启时，后续正常自动续费仍按原规则计费；改期本身不收费。
- 若是系统因到期暂停且新时间在未来，解除到期暂停，保持关机；管理员可通过既有开机操作启动。手动/风控封停保持。此入口不继承自动补续成功后的自动开机授权。
- 改为过去的时间时，弹窗提示后续正常自动续费、暂停及回收规则；接口不立即发停机或删机命令，不重置已有暂停保留期。
- 无到期时间的实例不增加期限；已删除或已进入清理的实例不能恢复。管理员校正尚未进入删除流程的实例可改变期限，这不放宽客户续费的72小时截止限制。

## 一致性与记录

打开弹窗单独读取最新状态，保存带版本摘要。实例、归属、位置、期限、暂停或自动续费状态已改变时拒绝旧修改，要求重新读取；5秒详情刷新不覆盖输入中的草稿。锁与原续费/到期处理共用，转移、未完成任务/还原/快照/反代、自动补续开机待重试及宿主维护期间保留门禁。

弹窗与管理员详情接口的客户/宿主/客机绑定核对；同一实例ID转移、换机或归属往返变化会同步关闭旧弹窗，旧读取/保存回执不显示成功。业务队列忙时立即拒绝，不把交互改期排在长远端任务后超时执行；数据库锁等待与事务均有上限。已经取消的自动开机任务不再阻塞，仍需重试的任务继续阻塞。

日期严格校验真实日历与UTC年份边界；夏令时跳过或重复的本地时刻不提交，显示具体提示。编辑期间设备时区变化要求重新读取，防止同一输入变成另一真实时刻。未改动原日期不能因显示精度而截断毫秒。

服务端要求管理员网页会话、允许的管理端Origin，事务内锁定并复核当前管理员角色、账户和会话撤销，保留平台恢复保护。客户API不能使用此权限。原子审计 `instance.expiry_update` 保存管理员ID、客户ID、实例ID、前后UTC时间与是否解除系统到期暂停；审计失败则改期回滚。重复旧请求冲突，相同当前时间不重复记审计。

## 已验证及范围

- 真实本地PostgreSQL＋实际Fastify路由：严格日期/ID/额外字段、权限/Origin/session、改期精度、无账务变化、并发双提交、真实行锁等待后续费/归属/删除/撤权冲突、任务与维护门禁、审计故障回滚和恢复保护。
- 实际`performRenewal`与改期交叉：已扣成功的续费不会被旧改期覆盖；改期后旧续费快照拒绝且不补扣。
- 真实Vue/Chrome＋受控API：三语、三宽、深浅色18组，时区和DST跳时、未改秒值保留、单提交、错误后重新读取、键盘退出/焦点恢复、旧会话/角色/实例/缓存回执与错误回执拦截。
- 复审新增真实JWT签名＋生产鉴权函数＋PG：客户/宿主所有者/伪造角色、坏签名、过期/无sid/撤销会话、降权/封禁均拒绝；直接服务调用仍复核权限。实际详情路由仅管理员得到编辑绑定，用户重命名/资源配置夹带期限和role不改期；免费延期不增加实付可退上限。
- 复审新增Chrome验证：实际API顶层错误码映射、同ID客户/宿主/客机变化和归属往返、DST回拨歧义、UTC跨年份、编辑中变更时区；相关失败旧日志保留。本地证据索引为`logs/admin-expiry-review-evidence.json`。
- 类型检查、相关守卫、测试清单及双端构建与包边界检查。本次无数据库迁移，无生产操作；不是线上客户流程验收。
