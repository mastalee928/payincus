# v1.8.3 网页升级与检查

本版修复再次故障隔离没有重新核验、转移数据库并发冲突和五项页面反馈。发行进度见 [验证记录](release-v1.8.3-validation.md)。本次由 owner 自行网页升级；维护 agent 没有执行生产 OTA、改隔离标记或操作客户实例。

## 网页升级

1. 超级管理员进入「版本更新」（`/admin/system-update`），点击「检查更新」，确认稳定目标为 **v1.8.3**。正式发行完成前不执行更新。
2. 点击「更新到最新版本」，确认后等待备份、迁移和唯一后台重启完成；重新进入，核当前版本 **1.8.3**，不要只看更新提示。
3. 正常升级不需要 OSS 还原。本版没有新增数据库迁移，累计仍为240；Agent保持v1.0.4，不移动已有tag或重发原资产。

## 再次故障隔离及 IPv4/IPv6

1. 进入「机器池」，找到仍提示故障隔离的宿主，打开恢复检查。在线和心跳正常说明管理通道可达，不能单独证明恢复条件满足。
2. 旧清理任务已完成但宿主又被隔离时，新版后台创建新的**只读核验周期**，保持原宿主身份。等待自然后台巡检；可在恢复页面点击原有重试入口，仍只重核，不能重放旧删除授权。
3. 查看客户实例、在途任务、账务、磁盘/快照/转发残留及身份检查。空库存确认通过后解除隔离；已售客户恢复检查通过时保留实例、磁盘与库存。身份不符或未知残留继续隔离，页面与日志保留原因，不能手工清字段绕过。
4. 恢复条件通过后查看宿主 IPv4 和 NAT 配置中的 IPv6 状态。IPv4/IPv6各自按原身份和入口规则自动续接；若IPv6仍未完成，对照具体阻断原因，不连续点同步当作恢复。
5. 在「日志」按宿主名、实例编号和时间搜索开通失败、退款/清理和回收核验。新失败保留首次原因、失败时间、核验阶段及下次动作；历史缺失的具体失败步骤无法由新版补出。

此前只读诊断确认目标宿主未换IP，其再次隔离来自新实例开通失败补偿后旧done任务没有重新排队；另一宿主換IP成功是独立事实。此次未替 owner 改生产隔离、网络或库存。实际升级后须按以上步骤核结果，不能以发行CI代替生产恢复成功。

## 工单公网 IP 与 OCI 账号

1. 管理员进入「工单」，打开关联实例的工单。实例卡片 IPv4 应是当前宿主公网地址，不能显示 `10.x` 等客机NAT内网地址。
2. 宿主公网地址正在同步时显示当前受信观察地址；没有已知公网地址时显示横线，不回退到内网IP。
3. 展开「详情」，查看 **OCI账号** 标签，值来自已有接入账号名称；旧宿主沿原账号标签来源显示。这里只显示名称。普通用户实例详情不会返回该管理员字段。

## 首页与品牌标题

1. 用普通窗口打开首页；再缩短窗口高度，测试125%和150%缩放。桌面地图随剩余高度收缩，底部帮助和联系方式可达；极短窗口允许纵向滚动。
2. 手机打开首页，滚到底部并展开联系方式；检查菜单、地图/球体交互和三态主题仍可使用，不出现横向溢出。
3. 管理员在「系统→品牌与外观」保存网站名称和网站副标题。用户端刷新后从首页进入「创建实例」（`/purchase`），浏览器标签应为 **网站名称 - 网站副标题**；多次返回首页再进入仍保持当前配置。

## 说明图标与余额

1. 「实例管理」卡片的自动续费说明图标：电脑悬停或键盘Tab聚焦可读说明，Escape关闭；手机点击显示，再点击关闭。说明包含余额扣款、余额充足和转移后关闭自动续费。
2. 使用专用测试账户进入创建实例后的确认页或购物车。余额支付项应显示 **账户余额(￥100.00)**，金额与账户实际可用余额一致；尚未读取成功时显示横线。
3. 切换测试账户后核金额来自新账户；付款后核余额流水、订单及实例交付。支付通道、币种和付款流程保持原有行为，不将实时余额附加到历史付款记录。

## 实例转移

1. 使用已授权专用测试实例和两个测试账户发起PUSH/接收。共享NAT实例须先正常关机；专属实例沿原转移规则处理。
2. 在实例管理卡片查看「等待转移」或「转移中」状态。重复PUSH、续费、自动续费切换和冲突开关机操作应受限制，不能重复发起；刷新或重新进入仍能读得后台状态。
3. 在「实例转移」查看持久结果。数据库并发更新时，后台最多四次重新提交；仍冲突则保留阶段并退避，自然五分钟任务和后台重启后按原授权续接。页面显示人可读原因，不显示Prisma/SQL原始堆栈。
4. 转移完成后，新用户核实例归属、原磁盘/UUID/已付到期及网络；转移手续费只记一笔。自动续费关闭，新用户自行决定开启，并按通知重置实例凭据。专属地址保留；共享实例转移中的资源清理仍沿原固定计划执行。
5. 授权撤销、身份变化、新资源或不满足转移条件时继续保留原任务和原因；不能用重建客户、删除新资源或重新扣费“修复”。

## 验证范围

本机验证使用隔离 PostgreSQL、受控mTLS Incus/Caddy边界、真实Vue/Chrome；发行双架构首装中的OSS是本地传输替身。真实OCI/原Agent与客户公网持续观察、真实OSS全新B完整灾备、独立备用接管、近千台和72小时仍需各自验收。网页升级成功也不代表这些目标全部完成。
