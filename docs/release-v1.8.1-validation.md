## 本次行为

- 直接购买进入独立订单确认页；购物车保留批量结算。
- 余额与第三方购机付款分开核销。第三方付款确认到账后自动交付，无需再次确认，不经账户充值余额。
- 未付款可更换支付方式；支付宝、微信支付分别显示，各 USDT 链标识独立。删除购物车商品后不会被旧未付单锁住新选择。

- 保留原控制、WireGuard、SSH、Incus 和 Agent 身份；暂停业务期间核验连接、原实例、账目及库存，原 Agent 心跳恢复后才显示全部还原完成。

## 安装与恢复修正

本轮同时修复了恢复命令退出时资源未释放、后台关闭钩子注册过晚、严格 umask 下状态文件不可读、数据库 OID 类型导致回退误判、连续恢复触发 systemd 启动限制及恢复任务维护锁交接。启动限流只在确认为 `start-limit-hit` 后重置并重试一次；维护锁最多等待 30 秒，取得锁后才验签和执行，超时仍拒绝并行维护。

旧鉴权和购买浏览器测试补齐了当前恢复会话、余额及直接购买入口的依赖和断言；没有为了通过测试放宽支付或权限边界。历史失败与后继通过步骤保留在本地发行证据中。
