# v1.8.0 自动恢复与删除故障预案

此文件描述源码行为与验收边界，发行终态以 HANDOFF.md 为准。生产主控由 owner 自行更新；本轮没有执行生产 OTA、重启或客户实例操作。

## 自动处理范围

| 情况 | 系统处理 | 完成条件 |
|---|---|---|
| 换机交付完成，旧机仍运行 | 交付切换同事务保存原宿主回收任务；自动停止、删除旧机并核验 | 原实例、系统卷/快照、专属公网转发均消失，宿主空机资格通过 |
| 新目标已创建但启动失败或回执丢失 | 创建前持久保存原宿主与任务标记，创建后保存 UUID；失败进入自动回收队列 | 仅原任务目标可删除，目标清空回执后继续核验原客户机器 |
| 开始创建前发现目标同名实例 | 只读核验，保留该实例；任务不能冒领删除权 | 远端空机核验通过才恢复未使用目标库存 |
| 普通隔离宿主已经为空或仍有正常已售机器 | 后台只读检查实际实例、磁盘、网络和原登记 | 空机可售条件或已售机器身份通过后自动解除隔离 |
| 换机在创建目标前失败，历史源实例被隔离 | 读取既有成功交付、原宿主身份、实例 UUID/创建时间与实际地址转发；自动恢复源的就绪标记 | 原客户机器运行且网络一致；不停止客户、不释放已售库存 |
| 宿主已安装但证书引用缺失 | 使用既有面板证书、已保存宿主 TLS 身份验证后补齐引用 | 原 mTLS 身份得到受信响应 |
| 生成 Agent 安装命令导致历史认证失配 | 在原 SSH/WireGuard 身份下仅对齐当前已授权 Agent 配置；只重启 Agent | 原受信 Incus 可用，当前 Agent 身份实际心跳恢复 |
| 管理员完整删除、用户销毁中断 | 已通过原权限/邮箱授权的请求先落库；启动及后台循环自动续接 | 远端删除与磁盘/快照/转发释放核验后，账目、地址与资源计数同事务结算 |
| 批量删除第一台失联、页面关闭或请求超时 | 整批通过校验的意图先持久化，再执行远端删除；逐项可续接 | 每项独立完成，失败不丢弃已接纳项 |
| 到期未续费 | 保留三天封停宽限及自动续费优先；保存原远端身份，再删除；每轮自动续接 | 当前付费期限仍到期、无手工封停或活跃任务、原机删除已确认 |
| DELETE 已接受但回执丢失 | 保留库存占用，重连后读取原目标；确切缺席时不重复发 DELETE | 同一原宿主的 guest/卷/快照/forward 缺席 |
| 数据库提交失败或主控重启 | 意图/UUID 及阶段持久保存；重新核验远端后继续事务 | 不重复退款，不按旧资源数字重复扣减 |
| guest 已删但磁盘仍残留 | 自动退避复查；不把接口成功或 guest 404 当成磁盘释放 | 存储清单无原系统卷/快照 |
| 网络、DNS、Agent 暂时不可用 | 独立有界请求与持久退避；队列分批轮转，单项失败继续处理其他项 | 原通道与原身份重新通过验证 |
| 同名 guest 被替换、宿主身份改变 | 保留数据和隔离，记录原因并自动重新检查 | 仅原身份恢复才继续；不重新信任未知机器 |
| 权限被撤销、出现较新维护任务 | 重新核验原授权/任务绑定；保护期间不做破坏性操作 | 原授权及任务条件重新满足 |
| 续费与删除竞争 | 实例计费串行、数据库行锁及版本/到期时间比较 | 已成功续费的实例不被旧删除快照接管 |
| 恢复保护生效 | 停止删除、退款及库存释放，保留意图 | 保护按原流程解除后自动继续 |
| 通知服务失败 | 删除/退款已完成的事务不回滚、不重放 | 账目和释放回执独立于通知传输 |
| 仅移除数据库记录 | 保留远端机器与磁盘，标记不可售，不被自动回收接管 | 此模式不等于完整删除，不自动释放保留磁盘 |

用户销毁继续强制原一次性邮箱验证，且不退款；管理员单删继续免二次验证且不退款，独立“删除并退款”及宿主批删保持所选规则。自动续接不要求再次确认、重试按钮或逐台 SSH；权限撤销不会被自动恢复覆盖。

## 持久状态与界面

- migration 234–236 分别保存宿主回收、管理修复与实例删除意图。
- 宿主回收与管理修复显示系统当前状态及下次自动检查时间；受保护任务继续检查，不伪报已完成。
- 机器池默认库存，防滥用移至次级标签。宿主公网 IPv6 位于公网 IP / OCI 账号下一行，多地址只显示文本，不添加复制按钮，未取得地址为“—”。
- 单台与批量“检查与恢复”只展示自动处理进度，后台重试不依赖页面打开；页面读取失败保留已有结果并自行重读，不靠反复点击或确认推进。
- 后台“日志”可按宿主名/编号查看每轮处理步骤、原因、结果和下次重试；历史到期巡检 JSON 显示为三语摘要，正常开始显示“已开始”，不误判为失败风险。原结构化记录保留，损坏记录不假报成功。
- 原成功换机历史可以接管；旧普通删除请求若没有持久意图，不能仅凭错误状态推断仍有删除授权。旧到期清理若没有原 UUID 且远端同名实例仍在，保留保护；确切缺席可继续结算。
- 库存计数以实际仍占用实例重算；专属宿主仍需规格、协议、在线及空机检查通过才能可售。

## 本地验证与未完成证据

本地 PostgreSQL 16 已应用全部236迁移；管理员/用户删除真实路由+mTLS HTTP替身、换机回收、源恢复、管理身份修复、到期续费竞争、代理站点持久清理、邮箱授权专项分别验证。替身故障注入包括离线、丢回执、卷残留、UUID变化、撤权、恢复保护、重复执行、事务回滚及进程中断；不能称为真实 Incus 或生产实测。

Linux CI 新增真实运行容器、快照、存储卷和公网转发删除，并分别调用底层删除、换机回收 worker、通用持久删除服务，核 PostgreSQL 可售库存；真实 systemd Agent 心跳恢复与文件/权限边界另验。其执行结果、同提交 AMD64/ARM64 首装/恢复、正式资产身份须在 HANDOFF.md 补充后才能宣布发行完成。

Incus 外部管理员在最后一次身份读取与按名称写入之间的并发替换，仍受 Incus API 自身条件写入语义限制；本轮不把 UUID 前后核验宣称为消除了所有外部并发窗口。独立 OSS 新机恢复、完整网关接管、近千台性能及72小时验收不在此次通过结论内。
