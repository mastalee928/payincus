# 实例独立磁盘与回池核验

本批候选 v1.8.11 / Agent v1.0.15。此文记录源码与隔离检查，不代表目标主控已经部署或正式发行。

## 现场原因

旧 Btrfs 共享池虽有 30GiB qgroup，客机 statfs 仍显示整个 34GiB 文件系统。改用 LVM thin volume，每卷独立 Btrfs，真实文件系统容量和用量属于当前实例；没有修改 df 或 SSH 工具读数。旧宿主仅在数据库与远端都确认无实例、无任务、无非镜像卷后转换；用户已自行删除全部实例，agent 不重复删除。

## 五项复核

1. **磁盘与库存**：新接入和旧空池复用同一准备器；真实卷/快照/回池删除与重装容量测试。前轮 14 种原生交付通过。新增 1GiB 重卖测试在 Btrfs 镜像缩容阶段失败，尚未写满；产品最低规格为 10GiB，改按实际边界测试 10GiB 重卖并写入超过 10GiB，错误输出留在内存，避免磁盘满后丢失诊断。新原生终态仍待。
2. **管理员与任务权限**：立即核验需要当前有效管理员和未撤销会话；伪造角色、普通用户、失效会话拒绝。唤醒只更新原任务时间，不重置 revision、操作者和删除证据；records-only 与灾备接管记录不转为自动删除。
3. **自动恢复与并发**：临时未就绪不再进入 30 分钟阻断，15 秒后可被原 30 秒队列继续检查；正常删除提交后立即核验。每个宿主去重，按钮只选该宿主，不受其它队列运行挡住；历史换机原机恢复保持原任务与交付证明。进程中断仍沿数据库任务续接。
4. **界面与异步**：“核验”位于“关闭”左侧，手机保持同行和 44px 热区；复用现有焦点管理。重复点击、失败重试、切换宿主后旧 GET/POST 回执、关闭窗口、三语、两宽、深浅主题均经过真实浏览器。只读回池核验不再误显示正在删除旧实例，临时原因分为工具/存储/接入/网络。
5. **发行与实际结果**：2560637e 双架构 14 项 Incus 兼容与 Agent/Alpine、双首装/六个 v1.8.10 原 worker 升级回滚预览通过。该来源 CI 两项上述 1GiB 测试失败，其余终态继续核对。新核验功能本地真实 PostgreSQL 的 cleanup/source/recovery/HTTP 入口及 mTLS 删除/退款回归通过，前端路由/i18n/磁盘守卫通过；同最终提交 CI、原生写满、实际双包与主控热更新实购尚待，不能据此发行。
