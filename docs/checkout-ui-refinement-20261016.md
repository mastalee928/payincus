# 购物车布局精修验收（2026-10-16）

本次基于正式版 v1.6.2 之后的源码进行界面精修，与此前的 [购物车界面验收](checkout-ui-acceptance-20261016.md) 分开记录。此轮没有更新正式 Release、标签或安装包。

## 改动范围

- `client/src/views/CheckoutView.vue`：精简标题区，集中商品单价、开通费及小计，增大文字和操作区域；登录设置放在清单下方，桌面结算栏保持可见；保留国旗、规格、系统、数量及全部错误提示。
- `client/src/locales/{zh-CN,zh-TW,en}.ts`：补充空购物车提示，以及整单共用登录方式的说明。
- 极窄屏将登录选项纵向排列，标题与数量分行布局。名称标签、生成名称预览和错误提示分别建立关联，数量按钮可区分不同商品。
- 只调整模板、局部样式和文案。比较 `<script setup>` 与基线，除 `Check` 图标导入外完全一致。金额计算、库存校验、价格确认、下单请求、幂等、轮询、认证和后端接口未改变。

## 浏览器验收

隔离预览挂载实际 CheckoutView 和购物车 store，商品目录及订单 API 使用示例数据，不调用真实扣款与开通。

- 两种配置三台主机：月费 49.70、开通费 6.00、合计 55.70；增加一台后对应为 59.60、9.00、68.60。
- 移除首项后剩余 29.90，零开通费时不显示费用行。
- 缺货时仍定位问题商品；移除缺货项后，未确认涨价仍提示确认并拦截付款。
- 长名称错误关联到输入框，名称预览不再被读作标签；没有密钥时默认密码登录，改选密钥后显示原因并禁用付款。
- 1280 px 桌面、390 px 手机以及 320 px 英文深色均检查。没有页面横向溢出，付款入口只有一个，窄屏登录选项没有挤压。
- 真实普通用户会话在更新后验证桌面与手机页面、价格变动提示及移除操作，浏览器无错误日志。原购物车为空，测试完成后恢复为空；没有创建订单或扣款。
