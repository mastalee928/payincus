# v1.8.4 网页升级与检查

从[正式Release](https://github.com/mastalee928/payincus/releases/tag/v1.8.4)及[验证记录](release-v1.8.4-validation.md)核源码和资产。本版已完成正式发行核验，目标生产环境仍需自行升级和验证。由owner自行网页升级，以下业务验证使用专用测试账户与已授权测试实例。

## 网页升级

1. 管理员进入「版本更新」（`/admin/system-update`），检查更新，确认稳定目标v1.8.4及验证记录中的源码提交。记录升级前版本与时间。
2. 点击更新并等待备份、迁移、校验及唯一后台重启完成；回到版本页核1.8.4、源码及新部署时间。失败保存任务编号和具体阶段，查看回滚结果，不能以开始提示当成成功。
3. 本版包含241个累计迁移，新增宿主安全维护状态。Agent独立版本v1.0.5包含启动标识上报；在机器池查看实际Agent版本、心跳和实例状态，不能用面板版本代替Agent部署事实。

## 管理员邮箱与实例改期

1. 「用户管理」选择测试用户，邮箱右侧细线铅笔应始终同行；编辑并保存新邮箱，列表刷新。原密码、2FA、余额、实例与封禁状态保持，用户需重新登录，旧验证码不能继续使用。自己的邮箱仍从个人设置验证后修改。
2. 无效/已占邮箱应拒绝；两个窗口编辑同一用户时，旧表单要求重读，不覆盖最新值。普通用户没有管理员编辑入口，API亦受管理员鉴权保护。
3. 进入测试用户实例「信息→基本信息→到期时间」修改准确时间，核设备时区、秒和审计前后时间。改期本身不扣费、不退款，不自动开机；系统到期暂停改未来仅解除到停止状态，手动封停保持。

## 自动续费与充值补续

1. 测试实例开启自动续费，余额不足时查看失败通知和到期状态：不再因三次失败关闭意愿。系统到期暂停起72小时内可补续；充值到账足额后触发，五分钟巡检兜底。
2. 同秒到期的多台实例仅充值够部分续费的金额，核按到期时间/实例ID顺序逐笔处理，已续一台只扣一次，余额不够的保留意愿。
3. 系统到期暂停自动补续成功后查看开机任务与实际运行状态；开机失败或断线只重试恢复，不再次收费。原手动关机、手动续费和到期前续费不新增开机。
4. 到保留期截止或开始删除后不得续费/补扣。删除及反代/磁盘残留未确认前仍占库存，确认空机后回可售；账单与审计保留。勿为测试修改生产账目、原身份或隔离标记。

## 安全维护与网关

1. 「机器池」查看每台宿主安全状态，点开检查阶段、失败原因和下次动作。适用官方SSH修订应保持原客户密码；使用专用客户核新SSH登录及已有连接。部分SSH完成不等于AppArmor等全部通过。
2. 本版不会放行尚未原生验证的自动重启方案；缺身份、未知持久属性、自定义服务或未满足隔离条件均保留具体原因。不要手动清保护字段来变绿。
3. 已配置主控兼网关的「网关」页面只显示重新检查，反复点击只读检查；原在线宿主、客户网络和当前管理身份保持。检查失败应显示原因，不变回首次安装。

## 首页、IP与付款

1. 电脑切换全部/各洲，核区域聚焦、城市与地区购买目标一致；缩放浏览器和调整窗口，标签不跨地理区域。手机全部无城市字，选洲后看欧洲、春川、新加坡/新加坡西部与瓦尔帕莱索，核触摸点选与拖动。
2. 三语、深浅、横竖屏查看导航和购买入口；指定品牌、导航和主标题不可选中，其余文本与输入保持原行为。
3. 核机器池、客户实例和管理员工单当前公网IPv4一致、IPv6状态及原转发；无需为本版换生产IP。存在隔离时按具体原因处理，不连续同步或删标记绕过。
4. 专用账户核余额购买、充值到账、订单/续费/退款流水与金额，重复回执不重复扣款。真实支付通道须使用已授权测试交易。

## OSS与日志

在「阿里云OSS」查看已保存配置、连接测试与完整备份任务；任务真正成功后记录版本/大小/时间。正常升级无需还原。真实新B灾备另按完整恢复方案验收，面板备份不含客户磁盘。管理员日志按时间、用户及实例查修改邮箱、改期、续费、开机、删除/回池和安全维护，保存失败阶段、原因、重试及最终回执。
