# 管理员修改用户邮箱

下一版源码：管理员后台「用户管理」中，点击用户邮箱右侧的细线铅笔图标，读取当前邮箱、填写新邮箱后确认。手机与电脑入口一致，图标带键盘可读标签和悬浮说明。自己的账号不显示此管理入口，仍从个人设置验证后改邮箱。

管理员改他人邮箱不要求用户验证码，提交前须核实归属。支持原账号未设置邮箱；禁止清空、同邮箱、无效地址及占用其他账号邮箱，遵循已有邮箱域名策略；地址去首尾空白并统一小写。被封禁用户改邮箱后仍封禁。

保存事务同时完成邮箱变更、未使用新旧地址验证码失效、该账号操作验证失效、Web访问/刷新会话撤销和管理员审计。限流所需的验证码历史保留；当前网页终端会话关闭，用户需重新登录。账号密码、两步验证配置、余额、角色、封禁状态及实例不变，不下发宿主/实例命令。OAuth绑定和独立Public API凭证不因邮箱变更自动删除。

GET/PUT `/api/users/:id/admin-email` 仅限有效管理员Web会话，保存要求管理端来源；事务内重新核当前角色、状态及会话撤销，演示站和恢复保护拒绝。旧通用profile接口不再接受管理员给他人改邮箱，以免绕过专用编辑器。普通用户个人改邮箱原验证码流程保持。

编辑读取的版本绑定账号状态与更新时间；账号并发变化要求重新读取，网络/服务器失败也先读取实际结果，不盲目重试。邮箱占用与注册共用数据库锁；审计失败整笔回滚。审计记录操作者/目标ID及脱敏前后地址，不保存明文邮箱或验证码。
