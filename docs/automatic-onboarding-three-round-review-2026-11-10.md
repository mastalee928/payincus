本轮围绕纯净 Alpine／Debian 宿主从 SSH 接入、系统准备、非特权加固到一机一卖可售，完成三轮代码审查与本地修复。基于分支 `codex/automatic-hardening-grub`，HEAD `2620f05ba44a7ffd23bb9a3fe84a73aecb7109c4`；新增修复尚未提交，精确文件及测试摘要在 `logs/onboarding47-evidence-index.json`。此前各阶段未提交修改均保留。

本轮没有连接主控、真实宿主或客户，没有部署、提交、推送、打 tag 或发行。代码审查完成不等于纯净系统原生接入验收完成，也不改变此前生产证据。

## 第一轮：权限、任务租约与 SSH 身份

检查入口管理员限制、凭据保存与读取、重试意愿、SSH 指纹、后台接管、网关登记及关键入库。

- **过期租约仍可能继续执行**：原部分流程只比较 token／状态，心跳和检查点可把同 token 的过期租约续长。新增统一当前权限／租约检查；任务须未删除、running、token 匹配、期限有效，创建批次的账号仍为启用管理员，且不处于恢复保护。心跳和检查点更新也要求租约尚未过期。
- **远端步骤之间缺少当前授权复核**：在 worker 的 SSH 下发步骤、身份检查、网关登记、存储创建前及关键事务增加检查。TLS 指纹入库先锁宿主、重读当前指纹，再检查当前租约，防止慢响应覆盖新指纹；存储池记录随最终安装状态在事务中保存。
- **一次显式重试可能被后台重复用来接受不同身份**：当前系统认证和无客户预检成功后，在该次重试意愿中固定已验证 SSH 指纹。后台续接仅接受它；新的管理员显式重试生成新的意愿。原有正式宿主身份保护继续保留。
- SSH 密码沿用上一阶段严格 AES-256-GCM 读取：不同随机 nonce，错误 key、篡改及旧明文拒绝；API／日志不返回凭据，成功接入清理临时凭据。没有关闭密码登录。

验证：真实本地 PostgreSQL 与回环 SSH 协议专项覆盖过期／换 token／管理员降权、旧系统重试、认证失败与客户预检拒绝、已确认指纹拒绝变化、重复 IP、旧 peer 清理及响应丢失续接。网关系统命令为测试替身。权限检查是每步下发前复核，不能撤回已经下发的远端命令，也不宣称数据库授权与远端执行之间具有原子事务。

主要文件：`server/src/services/onboarding-authority.ts`、`onboarding-lifecycle.ts`、`server/src/workers/hostOnboardingWorker.ts`。

## 第二轮：系统准备、安装并发和中断续接

复核 Alpine／Debian 与 AMD64／ARM64 系统识别，UTC 同步、ipinfo 当地时区、依赖、BBR、swap，以及安装器回执。

- **下载或安装进程可跨 worker 继续运行**：增加宿主文件锁；锁忙时自动退避，不启动第二份。轮询在 runner 尚未写完 PID 回执的启动窗口也按活动锁继续等待。
- **下载中断与安装中断混淆**：回执分为 downloading／installing。取得锁后只对确定的下载中断自动重新下载；未知安装中断仍拒绝自动重放。原依赖专用 exit 75 保留有限退避；普通错误／超时不解释为重新安装授权。
- **进程回执不完整与 PID 复用**：校验 PID 为大于 1 的数字，核 boot ID 与 `/proc` 启动 tick。进程身份写入失败时不启动安装器；完成回执写失败不报告成功。旧无 tick 回执保留原 boot＋PID 兼容，不能据此宣称旧进程身份完全防复用。
- **常驻服务可能继承安装锁**：由等待安装结束的 runner 持锁，实际安装器及其服务关闭该描述符，避免安装成功后一直被判忙。runner 异常退出但安装状态不明时仍保留 installing 保护。
- **WireGuard 私钥半写入**：先写随机临时文件，验证能导出公钥后再替换；不把残缺内容当成有效密钥继续登记。

验证：执行生成脚本的隔离 shell 测试覆盖四个系统／架构组合、依赖与时间失败、保留原 key、锁忙、下载续接、未知中断拒绝、非法 PID、回执路径写失败、完成写失败、子安装器不继承描述符，以及正常完成。另有 7 项时区与 10 项 swap Python 测试。Windows Git Bash 的 `flock`、系统命令及 `/proc` 等由明确替身提供；这不是 Linux 原生文件锁、包管理器或重启验收。

系统准备沿用上一阶段：固定 ipinfo HTTPS 地址、校验 IANA 时区、地理服务失败按小时补试但不停止 UTC 同步；BBR按内核能力开启，不替换内核；至少 1GiB 磁盘 swap 复用、不缩小、不关闭原 swap；依赖锁有界等待，不删锁、不杀其他更新进程、不关闭包签名与 TLS 校验。

主要文件：`server/src/services/onboarding-scripts.ts`、`server/src/lib/onboarding-retry.ts`、三语 locale 中的安装忙提示，以及 `server/scripts/test-onboarding-bootstrap-guards.ts`。

## 第三轮：加固完成、残留占用与真实可售

检查原接入维护续接、完整安全回执、当前宿主身份、原客户占用、失败任务清理与最终库存。

- **接入成功和库存判定不一致**：完成门禁原先只查 PENDING／PROCESSING，遗漏 FAILED 但仍持有宿主的重装／迁移清理回执。改用统一未结束创建任务条件；残留未清不能报成功，也不能释放库存。原清理回执完成后可以继续正常结束。
- **等待权限锁期间租约过期**：在最终成功更新的条件中再次检查当前租约期限；过期不能清凭据、写 succeeded。真实 PG 行锁专项确认执行已通过初始检查且阻塞在管理员锁，再使租约到期，验证拒绝；恢复有效租约后正常完成。
- **成功仍残留旧错误码**：完整完成时清除旧 errorCode，避免成功记录仍携带上次等待错误。

验证：两架构夹具分别通过实际队列、库存／公开目录与带行锁分配器。覆盖 FAILED 清理占用时库存 0、测试模拟原清理回执完成后库存 1，完成租约跨期拒绝，原维护不中途换请求，完整 verified 后中断可重新完成。远端内核、boot、命令及清理动作是替身或夹具，不将 DB 中模拟清理称为真实远端清理。

主要文件：`server/src/services/onboarding-security-gate.ts`、`server/scripts/test-onboarding-hardening-continuation.ts`。现有客户宿主始终保留占用，不通过改 DB 或减弱非特权检查恢复可售。
