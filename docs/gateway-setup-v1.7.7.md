# v1.7.7 网关配置与当前范围

管理员左侧「网关」位于「机器池」上方。首次进入先选择本机或外部网关，页面分别显示当前实际管理路径和准备中的候选。

## 本机网关

选择本机，检查并生成计划，填写或复用一次 DNS-only 固定域名，确认配置后查看核验结果。本机不填写 SSH 地址和密码。原管理身份、宿主连接和客户网络保持。

## 外部及备用候选

填写外部机器的 root SSH 地址、临时密码及指向同机公网 IPv4 的 DNS-only 域名；名称可选。系统自动规划至少 /20 管理地址池与端口，并检查冲突。SSH 检查和安装固定使用核验过的地址与已登记身份。

检查后生成安装计划。核对目标和变更，输入当前管理员密码、已启用的 MFA 和确认语句，点击确认安装。成功后领取并安全保存一次性的独立登录/恢复材料。安装回执与当前活动网关分别显示；候选安装不改变原宿主管理路径。

失败记录保留目标、时间、步骤及错误代码。冲突重规划受次数和总时间预算约束；超时不会继续发起新的检查。已开始安装或等待确认的候选需查看原任务；尚未投入管理且未写入的候选可退役后重新检查。部分执行中断保留身份和资源占用，不能通过普通重试覆盖。

当前缺依赖会明确报告缺少工具，不会自动重装系统或生成新身份。Debian 13/14 和关闭 IPv6 的检查路径已有源码与夹具回归，原系统完整远端安装真机验收仍待完成。

## IPv6 与灾备边界

主控/网关不要求启用公网 IPv6。宿主和客户 IPv6 通过原认证 IPv4 管理通道核验；主控协议族或路由不可用时采用客机核验，错误身份、出口与转发规则仍保持阻断。

本版交付独立页面、候选检查/安装入口、持久错误与容量边界。**独立网关迁移、备用自动接管、切回、新 IP 主控 OSS 恢复后的完整重连、唯一写者交接和千台实际批量应用尚未完成验收。** 不能把安装完成解释为双网关自动容灾可用。完整 P0–P6、AC01–AC34、公网整机失联及 72 小时验收继续保留。

发行、双架构首装、隔离恢复与生产升级分别以 HANDOFF.md 的实际证据为准。发布此版本不代表现有生产主控已升级。
