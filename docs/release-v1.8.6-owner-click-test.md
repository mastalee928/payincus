# v1.8.6 网页升级与自动接入检查

由管理员自行操作，先核[正式Release](https://github.com/mastalee928/payincus/releases/tag/v1.8.6)和[最终验证记录](release-v1.8.6-validation.md)。当前文档为候选准备，正式验证未完成前不视为已发行。

## 升级

1. 后台「版本更新」(`/admin/system-update`)检查目标v1.8.6，点击更新一次，观察下载、完整性验证、备份、迁移及服务恢复；完成后核版本与更新时间。失败按该任务保存具体阶段，不绕过校验或反复重装。
2. 机器池查看已登记宿主Agent逐步升级到v1.0.6及新心跳，等待防护回执通过。没有手工SSH命令或逐台开关；自动升级暂时失败时看宿主详情与管理员日志的实际原因。

## 新接入到可售

1. 已有商品分组与价格的前提下，在「机器池→对接」填准备好的纯净Alpine／Debian宿主SSH IP和密码。密码保存后接口及列表不显示明文。
2. 查看任务自动完成系统／资源识别、依赖与时间准备、管理连接、Incus／Agent、非特权加固及最终验证。包锁、短暂网络、资源等待等显示具体步骤并自动续接，无需反复点确认。
3. 完成后任务成功；无客户／残留的宿主显示可售，公开购买页的地区与配置库存同步。已有客户宿主保持占用，不应成为可售。
4. 若停留不可售，点「安全加固→详情」查看阶段、具体原因、已执行动作和下一次自动检查；后台「日志」按时间、宿主或任务查全过程。需要未验收引导方案／原身份冲突／残留未清等不能标绿，保留对应具体原因。

## 客户与管理隔离

仅用授权测试实例验，不用付费客户作故障试验。原SSH密码、新连接、普通全端口服务及IPv4／IPv6继续可用；从客户机请求OCI metadata应失败，云租户／邮箱不应返回；客户主动访问管理SSH／Incus API不可达。宿主Agent心跳及OCI IPv6发现正常。普通公网客户SSH来源保持，已识别管理侧验收连接看到宿主转换后的来源。公开门户80／443继续可访问，不能把公开域名可解析等同防护失败。

## 业务与日志

用测试账户核购买库存、交付后占用、原客户账期／订单／余额保持。暂停期余额足够补续后自动恢复运行；确认删除后不再扣续费，清理完成才回售。测试重装须是专用实例，核新系统交付、原记录及失败清理；不要为了验证直接删除真实客户。

OSS页查看正常完整备份结果，无需为本次升级点击还原。升级包验证与源码修复不等同真实OSS异机灾备或生产恢复。保留失败任务ID、时间和页面错误，勿把密码／token／密钥贴入公开日志。
