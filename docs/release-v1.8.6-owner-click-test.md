# v1.8.6 网页升级与自动接入检查

由管理员自行操作，先核[正式Release](https://github.com/mastalee928/payincus/releases/tag/v1.8.6)和[最终验证记录](release-v1.8.6-validation.md)。正式软件及资产核验已完成，本次未代升级生产。

## 升级

1. 先在后台 OSS／备份页确认最近一次完整备份成功，并保存其时间和任务ID；本次升级检查不需要点击还原。记录机器池空闲／占用数量，已有客户的实例ID、运行或停止状态、到期时间及公网地址，供升级后对照。
2. 后台「版本更新」(`/admin/system-update`)检查目标v1.8.6，点击更新一次，按网页确认继续，观察下载、完整性验证、备份、迁移及服务恢复；完成后核当前版本为v1.8.6及更新时间。失败从该页面的「任务日志」保留具体阶段和任务ID，不绕过校验或反复重装。
3. 机器池查看已登记宿主Agent逐步升级到v1.0.6及新心跳，等待防护回执通过。正常流程不需要手工SSH命令或逐台开关；自动升级暂时失败时看宿主详情与管理员「日志」(`/admin/logs`)的实际原因。面板更新完成和宿主Agent升级完成是两个状态，旧Agent缺少新防护回执时不应提前可售。
4. 对照已有客户的运行／停止状态、到期时间、地址、订单和余额。无客户宿主按完整回执恢复库存；有客户宿主保持占用。已验收方案确需重启宿主时会有短暂中断，程序应沿原身份自动重连并恢复原运行客户，原手动停止客户保持停止。

## 新接入到可售

1. 已有商品分组与价格的前提下，在「机器池→对接」(`/admin/host-onboarding`)填准备好的纯净Alpine／Debian宿主SSH IP和密码。默认SSH端口为22，非默认端口填写实际值；资源、分组和端口协议采用已有商品设置，不要求手填指纹、管理IP或在宿主运行安装命令。密码保存后接口及列表不显示明文。
2. 查看任务自动完成系统／目标架构识别、依赖、时间同步及ipinfo当地时区、支持时BBR、至少1GiB磁盘swap、管理连接、Incus／Agent、非特权加固及最终验证。原swap不缩小不关闭。地理接口暂时失败时先保持准确UTC并自动补试，不应影响账期或证书。
3. 包锁、短暂网络、资源等待等显示具体步骤并自动续接，无需反复点确认。记录任务ID，等待当前阶段和下一次检查变化；不能仅凭SSH连通、安装结束或Agent在线判断已经可售。
4. 完成后任务成功；无客户／残留且已有分组定价的宿主显示可售，公开购买页的地区与配置库存同步。已有客户宿主保持占用，不应成为可售。一台宿主成功交付给测试客户后，应从空闲库存扣除，不能再次出售。
5. 若停留不可售，点击该宿主的「安全加固」状态查看阶段、具体原因、已执行动作、尝试次数和下一次自动检查；后台「日志」按时间、宿主或任务查全过程。需要未验收引导方案／原身份冲突／残留未清等不能标绿，保留对应具体原因。不要通过清维护记录、改指纹、删回执或强制改库存解决。

当前允许自动修改引导并重启的原生验收方案仅为Alpine／GRUB／AMD64。ARM64／Debian已有完整防护时可以正常验收；需要未验收引导方案时仍会具体阻断，本版不保证任意纯净系统均能自动完成。AMD64与ARM64按各自宿主实际架构选Agent、组件和镜像。

## 客户与管理隔离

仅用授权测试实例验证，不用付费客户作故障试验：

1. 实例详情应显示正确宿主、系统、架构和地址。用原密码新建SSH连接，同时保留一条既有连接；错误密码应拒绝。客户容器必须为非特权，不能访问宿主目录、Incus socket或管理设备。
2. 从客户机直接请求OCI `169.254.169.254`，包括HTTP 80上的`/opc/v2/instance/`与Oracle认证头，应被宿主防护阻断，不能返回租户、账户邮箱或标签。不要将可能返回的云账户内容贴入公开日志；意外可达时保存时间与实例ID并报告防护失败。
3. 客户主动访问私有管理网段、已识别主控／网关管理SSH和Incus API应被阻断；公开门户80／443仍可访问。普通客户公网SSH保留原来源，已识别管理侧验收连接应看到宿主转换后的来源。公开域名可解析或第三方记录可查询，不等同管理隔离失败，也不承诺公网IP绝对隐身。
4. 测试客户正常公网连接、DNS和所选业务端口协议；TCP+UDP商品分别验证两种协议，TCP商品按其配置验收。宿主具备IPv6时另核客户IPv6，主控／网关没有IPv6不应妨碍客户使用。确认Agent心跳及宿主OCI IPv6发现正常。

## 业务与日志

用测试账户核购买库存、交付后占用、原客户账期／订单／余额保持。因到期暂停且仍在保留期内、自动续费意愿开启的实例，实际充值到账且余额足够后应补续并自动恢复运行，只扣一次；到账触发之外保留现有巡检兜底。多台同秒到期按到期时间、实例ID排序，每台核当前余额，不够当前一台可继续检查后续，不能透支或扣半笔。

沿现有保留期限核到期自动删除：进入删除流程或已删除后不得续费、补扣或因充值复活；实际实例、磁盘与转发清理确认后才回售。测试重装须是专用实例，核新系统交付、原记录及失败清理；不要为了验证直接删除真实客户。涉及扣款、重装或删除的页面操作仅用于预先安排的测试账户和测试机器。

OSS页查看正常完整备份结果，无需为本次升级点击还原。升级包验证与源码修复不等同真实OSS异机灾备或生产恢复。保留失败任务ID、时间和页面错误，勿把密码／token／密钥贴入公开日志。
