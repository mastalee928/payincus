# Third-party components used in PayIncus

## D3 Geo — mobile globe projection

The optional mobile globe preview uses d3-geo 3.1.1 for orthographic projection,
geographic clipping and SVG path generation. Coastline data is Natural Earth
1:110m (public domain); region city coordinates are GeoNames (CC BY 4.0), credited
in the page footer and HOMEPAGE_DEMO.md.

## Vue Bits — AnimatedContent

The application component at src/components/motion/AnimatedContent.vue adapts the
AnimatedContent module from [Vue Bits](https://github.com/DavidHDev/vue-bits),
the official Vue port of [React Bits](https://github.com/DavidHDev/react-bits).

The application version uses the existing GSAP entry point, component-scoped
cleanup, IntersectionObserver and a live reduced-motion preference. It does not
register or remove other components' scroll triggers.
